# TicTaZi releases

Downloads and the in-app update feed for [TicTaZi](https://github.com/Skheiller), a menu bar study timer for macOS.

This repository holds release builds only. The app's source code is private.

- **Download:** see [Releases](../../releases/latest).
- **Requires:** macOS 14 or later, Intel or Apple Silicon.
- **First open:** TicTaZi isn't notarized yet, so macOS asks you to allow it once in System Settings → Privacy & Security.

TicTaZi checks this repository for updates about once an hour while it's running, and only installs one when you say so.
